## 2. 设备类型

- 主控：ESP8266，ESP-12F
- 屏：0.96 inch I2C OLED，SSD1306
- OLED 地址：0x3C
- OLED 与传感器分别接线；本源码中 OLED 使用硬件 I2C，传感器使用一组显式引脚宏
- 注意：不同板子可能把传感器总线接到同一组或不同组 I2C，请按本文件的 D7/D8 接线核对

## 3. 引脚对应关系

### OLED SSD1306

| OLED 引脚 | 接到 ESP8266 / ESP-12F |
| --- | --- |
| VSS/GND | GND |

| SCL | D5 = GPIO14 |
| SDA | D6 = GPIO12 |

### 环境传感器 AHT20 + BMP280

| 设备 | VCC | GND | SDA | SCL | 地址 |
| --- | --- | --- | --- | --- | --- |
| AHT20 | 3V3 | GND | D7 = GPIO13 | D8 = GPIO15 | 0x38 |
| BMP280 | 3V3 | GND | D7 = GPIO13 | D8 = GPIO15 | 0x76 |

注意：D8 = GPIO15 上电必须为低电平，需要外接上拉电阻。

## 4. 烧录说明

ESP8266 通常只需要写 firmware.bin。使用备份固件：

```bash
sudo env PYTHONPATH=/home/hotyuo/.local/lib/python3.11/site-packages \
python3 -m esptool \
  --chip esp8266 \
  --port /dev/ttyUSB0 \
  --baud 460800 \
  --before default-reset \
  --after hard-reset \
  write_flash \
  0x0 /home/hotyuo/esp32-wsd/backups/2026-09-19/172.22.22.63/binaries/firmware.bin
```

如果当前烧录口不是 /dev/ttyUSB0，请替换 --port。

## 5. 注意事项

- 这台是 ESP8266 OLED 变体，不要把 ESP32-S3 的 firmware.bin 写进来。
- 当前 172.22.22.63 和 172.22.22.251 的备份固件 md5 相同，说明仓库中只有同一份 ESP8266 构建产物；如后续出现分别构建，应按 IP 重新归档。
- 不要用旧版 ESP32 的分区文件烧录 ESP8266。
