## 2. 设备类型

- 主控：ESP32-S3
- 屏：0.96 inch I2C OLED，SSD1306/SSD1315，4 孔排线
- OLED 地址：0x3C
- OLED 使用独立 I2C1 总线
- 传感器 AHT20 + BMP280 使用 I2C0 总线

## 3. 引脚对应关系

### OLED 4 孔接线

| OLED 引脚 | 接到 ESP32-S3 |
| --- | --- |
| VSS/GND | GND |
| VDD | 3V3 |
| SCL | GPIO13 |
| SDA | GPIO14 |

说明：OLED 地址为 0x3C，走 I2C1，与传感器 I2C0 分离。

### 环境传感器

| 设备 | VCC | GND | SDA | SCL | 地址 |
| --- | --- | --- | --- | --- | --- |
| AHT20 | 3V3 | GND | GPIO8 | GPIO9 | 0x38 |
| BMP280 | 3V3 | GND | GPIO8 | GPIO9 | 0x76 |

### MAX30102 体征传感器

| 引脚 | 接到 ESP32-S3 |
| --- | --- |
| VCC | 3V3 |
| GND | GND |
| SDA | GPIO14 |
| SCL | GPIO13 |
| INT | 未使用 |

说明：MAX30102 与 OLED 共用 I2C1。

## 4. 烧录说明

从本备份恢复 firmware.bin：

```bash
sudo env PYTHONPATH=/home/hotyuo/.local/lib/python3.11/site-packages \
python3 -m esptool \
  --chip esp32s3 \
  --port /dev/ttyACM0 \
  --baud 921600 \
  --before default-reset \
  --after hard-reset \
  write_flash \
  0x0  /home/hotyuo/esp32-wsd/backups/2026-09-19/172.22.22.164/binaries/bootloader.bin \
  0x8000 /home/hotyuo/esp32-wsd/backups/2026-09-19/172.22.22.164/binaries/partitions.bin \
  0xe000 /home/hotyuo/esp32-wsd/backups/2026-09-19/172.22.22.164/binaries/firmware.bin
```

如果只需要写应用固件，不重写 bootloader/partitions，请谨慎确认分区表没有变化。

## 5. 注意事项

- 这台设备是 ESP32-S3 OLED 变体，不要把 ESP8266 的 firmware.bin 写进来。
- 如果更换为 6 线 SPI TFT 屏，不能使用本固件/引脚配置。
- 串口通常使用 /dev/ttyACM0，若系统端口不同请替换 --port。
