## v1.1.0 更新日志

### 新增功能
1. **测试连通性** — 配网页面新增"🔍 测试连通性"按钮，保存前可先测试 WiFi 和服务器连通性
   - 测试 WiFi：连接指定 SSID，10 秒超时，返回 IP 或错误
   - 测试服务器：TCP 端口探测（手动模式下），返回可达/不可达
   - 测试结果实时显示：✅ 成功（绿色）/ ❌ 失败（红色）+ 错误原因
2. **保存后隐藏热点** — 保存配置后自动关闭 AP 热点，设备重启连接 WiFi
3. **60 秒 STA 超时回退** — WiFi 连接超时 60 秒自动回退到 AP 配网模式

### 变更
- Web 配置页面：「保存并连接」拆分为「测试连通性」+「保存并连接」两个独立按钮
- 保存响应页面：显示保存的 WiFi 名称、服务器模式、实时数据 URL

## 2. 接线图

### 2.1 屏幕 (ST7735 0.96" 160x80 IPS TFT LCD, 6引脚 SPI)

| 屏幕引脚 | 功能 | ESP32-S3 GPIO |
|---------|------|---------------|
| SCK     | 时钟 | 12 |
| MOSI    | 数据 | 11 |
| CS      | 片选 | 10 |
| DC      | 数据/命令 | 7 |
| RES     | 复位 | 6 |
| BLK     | 背光 | 5 |
| VCC     | 电源 | 3.3V |
| GND     | 地 | GND |

### 2.2 传感器 (全部独立引脚，不共用总线)

| 传感器 | 功能 | 总线/接口 | ESP32-S3 GPIO |
|--------|------|----------|---------------|
| AHT20  | 温湿度 | I2C0 SDA/SCL | 8 / 9 |
| BMP280 | 气压 | I2C0 SDA/SCL | 8 / 9 (与AHT20共用) |
| MAX30102 | 心率血氧 | I2C1 SDA/SCL | 14 / 13 (独立) |
| MIC    | 麦克风 | ADC | 4 |
| LED R  | 红LED | GPIO | 15 |
| LED G  | 绿LED | GPIO | 16 |
| LED B  | 蓝LED | GPIO | 17 |
| Buzzer | 蜂鸣器 | PWM | 18 |
| Speaker| 喇叭 | PWM | 21 |

**MIC 注意**: 裸驻极体咪头必须外接 4.7kΩ 偏置电阻到 3.3V，否则 ADC 恒为 0。

## 3. 烧录方法

### 方法一：一键脚本（推荐）

```bash
cd v1.1.0
./flash.sh
```

脚本自动检测串口，用 esptool 按分区表地址分别烧录 3 个文件。

### 方法二：PlatformIO（修改源码后）

```bash
cd /home/hotyuo/tio/firmware
sudo -E /home/hotyuo/.local/bin/pio run -e esp32-s3-tft7735 -t upload --upload-port /dev/ttyACM0
```

### ⚠️ 烧录警告

**禁止**手动拼接 `boot+part+fw` 合并镜像！bootloader.bin 仅 15104 字节 (0x3B00)，拼接后分区表会落在 0x3B00 而非 0x8000，导致 bootloader 找不到分区表 → 反复重启。必须用 `pio upload` 或 esptool 多地址分别烧录。

### 4.2 配网流程 (v1.1.0 新增测试功能)

1. 设备无 WiFi 配置 → 自动开启热点 `EnvMon-XXXX`
2. 手机连热点 → 浏览器访问 `http://192.168.4.1/`
3. 填 WiFi 名称 + 密码 + 服务器地址
4. **点击「🔍 测试连通性」** → 显示测试结果
   - ✅ WiFi 连接成功 + IP 地址
   - ✅ 服务器连接成功 + 地址:端口
   - ❌ 失败原因（超时/密码错误/无法连接）
5. 测试通过后点击「💾 保存并连接」→ 热点关闭，设备重启

### 4.3 Web 实时数据页面

设备连上 WiFi 后，通过 **设备 IP** 访问：

| 页面 | URL | 说明 |
|------|-----|------|
| 配网页面 | `http://<设备IP>/` | WiFi/MQTT 配置 + 测试 + 恢复出厂 |
| 实时数据 | `http://<设备IP>/data` | 实时传感器数据 |
| 数据接口 | `http://<设备IP>/json` | JSON 格式数据 |
| 恢复出厂 | `http://<设备IP>/factory` | 清除所有配置 |

配网模式下（AP热点），访问 `http://192.168.4.1/`

### 4.4 串口命令 (115200)

| 命令 | 功能 |
|------|------|
| `config` | 进入 AP 配网模式 |
| `factory` | 恢复出厂设置 |
| `status` | 查看状态 |

### 4.5 恢复出厂

三种方式：
1. **Web 界面**: 配网页面底部红色「🔄 恢复出厂设置」按钮
2. **Web URL**: 访问 `http://<设备IP>/factory`
3. **串口命令**: 输入 `factory`

### 4.6 语音输出

喇叭通过 GPIO21 LEDC PWM 驱动（独立通道 SPK_CH=1），报警时与蜂鸣器同时发声：
- **正常**: 无声
- **预警**: 无声（仅 LED 闪烁）
- **报警**: 蜂鸣器 2700Hz + 喇叭 880Hz，间歇鸣叫（500ms 响 / 500ms 停）

## 6. FAQ

**Q: 烧录后反复重启？**
A: 不能用合并镜像烧录。用 `flash.sh` 或 `pio upload` 按地址分别烧录。

**Q: 屏幕黑屏有背光？**
A: 检查 SPI 接线是否正确 (SCK=12 MOSI=11 CS=10 DC=7 RST=6 BLK=5)。

**Q: MIC 读数为 0？**
A: 裸咪头需要外接 4.7kΩ 偏置电阻到 3.3V。

**Q: MAX30102 不显示？**
A: 检查 I2C1 接线 (SDA=14 SCL=13)，确认传感器供电和 GND。

**Q: 如何查看实时数据？**
A: 设备连 WiFi 后，浏览器访问 `http://<设备IP>/data`。

**Q: 如何测试 WiFi 和服务器连通性？**
A: 配网页面点击「🔍 测试连通性」按钮，先测试再保存。

**Q: 保存后热点不见了？**
A: 这是正常行为。保存配置后热点自动关闭，设备连接配置的 WiFi。

**Q: 设备一直开热点怎么进 STA 模式？**
A: 串口输入 `factory` 清除配置，或等待 60 秒超时自动回退。
