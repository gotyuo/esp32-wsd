📡 非ESP设备接入 / HL7 & HTTP INGEST

HTTP JSON 接入

外网/非ESP设备可通过 HTTP POST 推送 JSON 数据,无需 MQTT。
URL:
Header: Authorization: Bearer <token>
Method: POST
Content-Type: application/json
Body 示例:
{
  "device_id": "ext-001",
  "temp_c": 25.5,
  "hum_pct": 60.2,
  "pres_hpa": 1013.0
}

HL7 v2.x 接入

支持 HL7 ORU^R01 观察结果消息,自动解析并入库。
URL:
Method: POST
Content-Type: text/plain
HL7 示例:
MSH|^~\&|VENT|ICU|ENVMON|SERVER|202608261200||ORU^R01|MSG001|P|2.5
PID||12345|12345||张三^A||19800101|M
OBR|1||12345^VENT|TEMP^TEMPERATURE
OBX|1|NM|TEMP^TEMPERATURE||36.8|C|35.0-37.5|N|||F
OBX|2|NM|HR^HEART_RATE||72|bpm|60-100|N|||F
OBX|3|NM|SPO2^OXYGEN_SAT||98|%|95-100|N|||F
