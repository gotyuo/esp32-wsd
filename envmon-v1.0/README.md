# 环境监测系统固件 v1.0

基于 ESP32-S3 的一体化环境监测终端固件（独立发布版）。

## 功能

- **传感器采集**: AHT20 (温湿度) + BMP280 (气压)，I2C 接口
- **屏幕显示**: GC9109 0.96" 160x80 IPS TFT（软件 SPI 驱动）
  - 6 页轮播：CONFIG MODE → 热点名 → IP → 温度 → 湿度 → 气压
  - 中文大字显示（温/度/湿/气/压 16x16 字模）
  - 每页 5 秒自动切换
- **AP 配网**: 连接热点后访问 192.168.4.1 配置 WiFi/MQTT
  - 支持自定义热点名称（保存后生效）
- **语音控制**: 麦克风（ADC1_CH3/GPIO4）检测声音，喊一声立即翻页
- **报警**: 共阴 RGB LED + 无源蜂鸣器 + MQTT 上报

## 硬件接线（一对一逐引脚）

> 使用说明：下表每一行都是一条物理连线。左侧是该模块上的引脚丝印，
> 右侧标明连接到 ESP32-S3 的 GPIO 编号或电源轨。

### AHT20 温湿度传感器（I2C，地址 0x38）

| 模块引脚 | 连接到 | GPIO / 电源 |
|----------|--------|-------------|
| VCC | 3.3V 电源轨 | 3V3 |
| GND | 电源地 | GND |
| SDA | ESP32-S3 GPIO 8 | GPIO 8 |
| SCL | ESP32-S3 GPIO 9 | GPIO 9 |

### BMP280 气压传感器（I2C，地址 0x76/0x77）

| 模块引脚 | 连接到 | GPIO / 电源 |
|----------|--------|-------------|
| VCC | 3.3V 电源轨 | 3V3 |
| GND | 电源地 | GND |
| SDA | ESP32-S3 GPIO 8（与 AHT20 并联） | GPIO 8 |
| SCL | ESP32-S3 GPIO 9（与 AHT20 并联） | GPIO 9 |

### GC9109 0.96" TFT 屏幕（SPI）

| 模块引脚 | 连接到 | GPIO / 电源 |
|----------|--------|-------------|
| VCC | 3.3V 电源轨 | 3V3 |
| GND | 电源地 | GND |
| SCK / SCL | ESP32-S3 GPIO 12 | GPIO 12 |
| MOSI / SDA | ESP32-S3 GPIO 11 | GPIO 11 |
| RES / RST | ESP32-S3 GPIO 6 | GPIO 6 |
| DC / RS | ESP32-S3 GPIO 7 | GPIO 7 |
| CS | ESP32-S3 GPIO 10 | GPIO 10 |
| BLK / BL（背光） | ESP32-S3 GPIO 5 | GPIO 5 |

### 麦克风（裸驻极体咪头）

> ⚠️ 裸咪头必须加偏置电阻，否则 ADC 读数恒为 0。

| 模块引脚 | 连接到 | GPIO / 电源 |
|----------|--------|-------------|
| 正极（信号） | ESP32-S3 GPIO 4 | GPIO 4 |
| 正极（信号） | 通过 **4.7kΩ 电阻** 接 3.3V（偏置） | 3V3 |
| 负极 | 电源地 | GND |

### 喇叭（无源，需 PWM 驱动）

| 模块引脚 | 连接到 | GPIO / 电源 |
|----------|--------|-------------|
| 正极（信号） | ESP32-S3 GPIO 21 | GPIO 21 |
| 负极 | 电源地 | GND |

### 共阴 RGB LED

> 共阴 = 公共端（COM）接 GND，R/G/B 阳极接 GPIO，需串联 220Ω 限流电阻。

| 模块引脚 | 连接到 | GPIO / 电源 |
|----------|--------|-------------|
| R（红） | GPIO 15 串 220Ω | GPIO 15 |
| G（绿） | GPIO 16 串 220Ω | GPIO 16 |
| B（蓝） | GPIO 17 串 220Ω | GPIO 17 |
| COM（公共阴极） | 电源地 | GND |

### 无源蜂鸣器

| 模块引脚 | 连接到 | GPIO / 电源 |
|----------|--------|-------------|
| 正极（信号） | ESP32-S3 GPIO 18 | GPIO 18 |
| 负极 | 电源地 | GND |

## 构建

```bash
pio run                 # 编译
pio run -t upload       # 编译并烧录 (/dev/ttyACM0)
```

## 烧录

- `release/envmon-v1.0-full.bin` — 仅应用分区，烧到 0x10000
- `release/envmon-v1.0-merged.bin` — 合并镜像（含 bootloader/分区表），烧到 0x0
- `pio run -t upload` 一键烧录
