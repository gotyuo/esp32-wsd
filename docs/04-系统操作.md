# 04 · 系统功能与操作指南 (v2.2)

## 系统架构

```
[AHT20/BMP280] [ECG] [PPG] [Breath]
     │             │       │       │
     └─────────────┴─── ESP32-S3 ──┘
                     │
             MQTT (18830)
                     │
              Mosquitto Broker
                     │
              FastAPI 后端 (12090)
              ├─ WebSocket (实时推送)
              ├─ REST API (Web UI / 第三方对接)
              ├─ AI 规则引擎
              └─ SQLite (15 张表)
                     │
              Web 监护台 (浏览器)
```

## Web 台 4 个 Tab

### ① 📊 监护屏（默认）
选一台设备，展示环境数据（温度/湿度/气压/信号强度）+ 趋势图 + 阈值配置 + 报警记录。

### ② 🖥 实时监护（v2.2 新增）— **ICU 主界面**

选一名患者，顶部 6 张大数字体征卡 + 底部 3 个面板 + AI 评估面板。

**体征卡（6 张，Canvas sparkline 实时曲线）**

| 参数 | 正常范围 | LV1 预警 | LV2 危急 |
|------|---------|---------|---------|
| HR / ECG | 60–100 bpm | <60 或 >100 | <50 或 >130 |
| SpO₂ | 95–100% | <95 | <90 |
| RR | 12–25 rpm | <12 或 >25 | <8 或 >35 |
| NIBP | 100–140 mmHg | <100 或 >140 | <90 或 >180 |
| Temp | 36.0–37.5℃ | 偏离 | <35 或 >39.5 |
| Glu | 3.9–6.1 mmol/L | <3.9 或 >6.1 | <3.0 或 >16 |

每张卡右下趋势箭头：**↗ 上升 / ➡ 平稳 / ↘ 下降**（基于最近 6 点加权 vs 首末点双参考）。

**下方 3 面板**
- 💊 运行中医嘱（drug / dosage / route / pump rate mL/h）
- 💧 出入量条形图 + 近期记录（含 + 按钮弹窗录入）
- 🔬 检验 / 血气列表（含危急值 CRIT 标记）

**🤖 AI 评估面板**
- 总体风险：🟢低 / 🟡中 / 🟠高 / 🔴危急（后者红色脉冲动画）
- 8 大系统状态：循环 / 呼吸 / 神经 / 内分泌 / 肾功能 / 血液凝血 / 酸碱代谢 / 液体平衡
- 自动生成临床摘要 + 处理建议（基于规则）
- 底部免责声明

### ③ 🏥 患者管理（v2.1 新增）
患者卡片网格 → 点击进详情弹窗（编辑/关联设备/删除/体征曲线/医嘱/LIS）。
支持手动备份数据库（`POST /api/backup`）。

### ④ 🖥 设备管理 & ⑤ 🚨 报警
设备注册/解除、报警事件时间线。

## 出入量录入（v2.2）

点击"实时监护"Tab 顶部"+ 出入量"按钮：
- 方向：入 / 出
- 类别：液体 / 尿 / 引流 / 大便 / 呕吐物 / 吸痰 / 其他
- 子类：生理盐水 / 白蛋白 / 血 / 胃液 / 痰 / …
- 量（mL + g，支持呕吐物/粪便的 g 输入）
- 途径：iv / po / drain / np / urine / rectum
- 操作者

实时监护页 IO 面板显示 24h 入出净平衡；AI 评估据此给出液体状态评分。

## 阈值与报警逻辑

- 任一指标超出上下限 → **报警 LV2**（红色快闪 + 蜂鸣 2.7kHz + 服务器记录）
- 任一指标进入距边界 **10%** → **预警 LV1**（橙色闪烁）
- 体征突变检测（固件端）：心率与上次差值 >30% → LV2 报警
- 服务器端 AI 评估每 24h 数据重新评分（详见《08-AI-评估规则》）
- 手动/服务器/ESP32 三个数据源通过 `source` 字段区分
