# 04 · 系统功能与操作指南

## 系统组成

```
AHT20 / BMP280 ──I2C──> ESP32-S3 ──MQTT(18830)──> Mosquitto ──> FastAPI 后端 ──> SQLite
                          │   │                                      │
                      ST7735屏  RGB LED + 蜂鸣器                  WebSocket / REST
                                                                     │
                                                             Web 管理仪表盘(8627)
```

数据链路：传感器采样（2 秒/次）→ 本地阈值判定（驱动 LED/蜂鸣器）→ MQTT 上报（默认 10 秒/次）→ 服务器入库 → 每分钟聚合 → 仪表盘实时展示与历史曲线。

## 管理仪表盘

浏览器打开 `http://<服务器IP>:8627`：

- **实时卡片**：温度 / 湿度 / 气压 / 报警状态，WebSocket 秒级刷新；
- **历史趋势**：3 小时 / 24 小时 / 7 天三档切换，红色底纹标出报警区间；
- **报警阈值与参数**：设置各指标上下限、上报间隔、报警与蜂鸣开关，保存后自动经 MQTT 下发到设备并持久化；
- **报警记录**：触发/恢复时间、原因、当时数值。

## 阈值与报警逻辑

- 任一指标**超出**上下限 → **报警**（红色快闪 + 蜂鸣，服务器记录报警事件）；
- 任一指标进入距边界 **10% 的预警带** → **预警**（橙色闪烁）；
- 回到安全区 → 恢复正常并自动销警；
- `*` 为全局默认阈值，设备级阈值优先生效。

## MQTT 主题约定

| 主题 | 方向 | 内容 |
|------|------|------|
| `envmon/{id}/telemetry` | 设备→服务器 | JSON：`t/h/p/rssi/uptime/alarm/fw/heap` |
| `envmon/{id}/status` | 设备→服务器 | `online` / `offline`（遗嘱消息，保留） |
| `envmon/{id}/config` | 服务器→设备 | 阈值与参数 JSON |
| `envmon/{id}/config/req` | 设备→服务器 | 上线时请求下发配置 |
| `envmon/{id}/config/ack` | 设备→服务器 | 配置生效回执 |

## REST API 摘要

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/health` | 健康检查（含 MQTT 连接状态） |
| GET | `/api/devices` | 设备列表与在线状态 |
| GET | `/api/realtime` | 各设备最新读数 |
| GET | `/api/history?device=&hours=` | 历史数据（>3h 自动用分钟聚合） |
| GET/PUT | `/api/thresholds` | 读取/保存阈值（PUT 后下发到设备） |
| GET | `/api/alarms?limit=` | 报警记录 |
| POST | `/api/ingest` | HTTP 备用数据注入（测试用） |
| POST | `/api/devices/{id}/push-config` | 强制向设备下发配置 |
| WS | `/ws` | 实时推送 |

> 若 `.env` 设置了 `ADMIN_TOKEN`，写接口需携带请求头 `X-Admin-Token: <令牌>`。

## 数据保留

原始遥测默认保留 **7 天**，每分钟聚合与报警记录保留 **400 天**，可在 `.env` 调整。
