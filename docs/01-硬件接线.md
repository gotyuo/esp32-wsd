# 01 · 硬件接线与引脚定义 (v2.2)

> 主控：ESP32-S3-DevKitC-1（N16R8 或 N8R2 均可）
> 所有引脚均为 GPIO 编号（不是丝印编号）。

## 体征传感器信号调理（ICU v2.2 新增）

三个体征 ADC 引脚（25/27/14）**必须**接外部信号调理电路，否则读到的只是噪声，服务器端也会收到异常值并触发 AI 误报。

### 血氧 / 脉率 —— MAX30102（已接入固件）
- **模块**：MAX30102（推荐）或 MAX30105，I2C 数字输出（660nm 红 + 940nm 红外）。
- **接线**：VCC→3V3、GND→GND、SDA→**GPIO 22**、SCL→**GPIO 23**，走**独立 I2C1 总线**，与 AHT20/BMP280 的 I2C0（GPIO8/9）完全分离、不共用引脚（地址 0x57）。
- **输出**：固件上报 `sp_o2`（血氧 %）+ `pr_hr`（脉率 bpm），50Hz 连续采样、4s 峰值检测窗口。
- **建议**：指夹式探头固定贴合手指，采集时保持静止以提高准确率。

### 心电 —— AD8232（已接入固件）
- **模块**：AD8232 单导联心电前端（推荐）；输出模拟信号接 **GPIO 1**（ADC1_CH1）。
- **接线**：VCC→**5V**、GND→GND、OUTPUT→**GPIO 1**；LO(+)/RA(-)/RL 接胸前电极。
- **输出**：固件上报 `ecg_hr`（心电图心率 bpm），内部 ~250Hz 采样 + QRS 峰值检测。
- **注意**：AD8232 必须用 5V 供电，切勿接 3.3V。

### 脉搏 / 呼吸（备用 ADC）
- **脉搏 PPG**：裸光电反射传感器经信号调理后接 **GPIO 2**（ADC1_CH2）。
- **呼吸**：阻抗呼吸带经调理后接 **GPIO 3**（ADC1_CH3）。
- **说明**：这两路为备用 ADC 通道；血氧 / 脉率 / 心电已分别由 MAX30102 / AD8232 负责，优先使用。
## 麦克风偏置电路（重要）

裸驻极体咪头内部是 FET，**必须**从信号脚到 3.3V 接一个 4.7kΩ 偏置电阻，否则 ADC 读数恒为 0。

```
3.3V ──┤ 4.7kΩ ├──┬── GPIO4 (ADC1_CH3)
                   │
            麦克风正极 ──┤
            麦克风负极 ──┴── GND
```

## 指示灯颜色编码

| 状态 | LED 表现 | 蜂鸣器 |
|------|---------|--------|
| 正常运行 | 绿色慢速呼吸 | 静音 |
| 预警 LV1（接近阈值 10% 以内） | 橙色闪烁 | 静音 |
| 报警 LV2（超出阈值 或 体征突变） | 红色快闪 | 间歇鸣叫 2.7kHz |
| 体征危急（HR<50 或 >130 或 SpO₂<90%） | 红色脉冲 | 鸣叫 |
| 传感器无数据 | 蓝色慢闪 | 静音 |
| 配网模式（AP 热点） | 青色呼吸 | 静音 |

## OTA 双 slot 分区

| 分区 | 地址 | 大小 | 用途 |
|------|------|------|------|
| ota_0 | 0x010000 | 1536 KB | 固件 slot A |
| ota_1 | 0x610000 | 1536 KB | 固件 slot B |
| nvs | 0xC10000 | 64 KB | NVS 存储 |
| ota_data | 0xC20000 | 16 KB | OTA 状态 |

固件 869 KB，剩余约 528 KB 可用于未来扩展。
