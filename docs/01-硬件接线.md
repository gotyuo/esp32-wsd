# 01 · 硬件接线与引脚定义

> 主控：ESP32-S3-DevKitC-1（N16R8 或 N8R2 均可）
> 所有引脚均为 GPIO 编号（不是丝印编号）。
> 说明：下表每一行都是一条物理连线。左列为模块引脚丝印，右列是连接的 GPIO 或电源轨。

|------|---------|---------------|------|
| AHT20 / BMP280（共用 I2C） | VCC | 3V3 | 3.3V 供电 |
| | GND | GND | 电源地 |

| | SCL | **GPIO 9** | I2C 时钟线 |
| GC9109 0.96" TFT（SPI） | VCC | 3V3 | 3.3V 供电 |
| | GND | GND | 电源地 |
| | SCL / SCK | **GPIO 12** | SPI 时钟 |
| | SDA / MOSI | **GPIO 11** | SPI 数据 |
| | RES / RST | **GPIO 6** | 复位 |

> 说明：I2C 总线上 AHT20（地址 0x38）与 BMP280（地址 0x76/0x77）地址不冲突，可直接并联。
> 若接线超过 20cm 或读数不稳，可在 SDA/SCL 与 3V3 之间各加 4.7kΩ 上拉电阻。
> GPIO 0/3/45/46 为 ESP32-S3 strapping 引脚、GPIO 26~37 为 Flash/PSRAM 占用，本设计已全部避开。

## 麦克风偏置电路（重要）

裸驻极体咪头内部是 FET，**必须**从信号脚到 3.3V 接一个 4.7kΩ 偏置电阻，
否则 ADC 读数恒为 0，语音检测失效。内部上拉（约 45kΩ）阻值过大，不足以提供偏置。

```
3.3V ──┤ 4.7kΩ ├──┬── GPIO4 (ADC1_CH3)
                   │
            麦克风正极 ──┤
            麦克风负极 ──┴── GND
```

## 指示灯颜色编码

| 状态 | LED 表现 | 蜂鸣器 |
|------|---------|--------|
| 正常运行 | 绿色慢速呼吸 | 静音 |
| 预警（接近阈值 10% 以内） | 橙色闪烁 | 静音 |
| 报警（超出阈值） | 红色快闪 | 间歇鸣叫 2.7kHz（可在后台关闭） |
| 传感器无数据 | 蓝色慢闪 | 静音 |
| 配网模式（AP 热点） | 青色呼吸 | 静音 |
