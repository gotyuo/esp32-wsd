# 01 · 硬件接线与引脚定义 (v2.2)

> 主控：ESP32-S3-DevKitC-1（N16R8 或 N8R2 均可）
> 所有引脚均为 GPIO 编号（不是丝印编号）。

## 体征传感器信号调理（ICU v2.2 新增）

三个体征 ADC 引脚（25/27/14）**必须**接外部信号调理电路，否则读到的只是噪声，服务器端也会收到异常值并触发 AI 误报。

### ECG 心电（GPIO 25）
- **前端芯片**：AD8232 或 ADS1015（推荐 AD8232，单电源 3.3V）
- **典型接法**：ECG 电极 → AD8232 输入 → 输出接到 GPIO25
- **带通**：0.5Hz–40Hz，采样后每 32 次均值降低噪声
- **标定**：当前固件系数 `ADC/30` 为占位值，需采集实测 ADC 均值反推真实心率校准

### PPG 脉搏血氧（GPIO 27）
- **传感器**：MAX30102（推荐，I2C 接口）或 TSL2591 双通道光敏
- **若使用 MAX30102**：占用 I2C SDA/SCL 需扩展到第二 I2C 总线（ESP32-S3 支持多 I2C），或使用 GPIO 转接
- **光路**：红色 660nm + 红外 940nm LED，光电探测器接收反射光
- **标定**：需要参考血氧仪进行 SpO₂ 校准

### 呼吸（GPIO 14）
- **传感器**：阻抗式呼吸带（Impedance Pneumography），两端贴片电极
- **原理**：胸廓扩张 → 阻抗变化 → ADC 电压变化
- **采样**：系数 `ADC/200` 为占位，呼吸频率 12–25 rpm，需实测校准

## 麦克风偏置电路（重要）

裸驻极体咪头内部是 FET，**必须**从信号脚到 3.3V 接一个 4.7kΩ 偏置电阻，否则 ADC 读数恒为 0。

```
3.3V ──┤ 4.7kΩ ├──┬── GPIO4 (ADC1_CH3)
                   │
            麦克风正极 ──┤
            麦克风负极 ──┴── GND
```

## 指示灯颜色编码

| 状态 | LED 表现 | 蜂鸣器 |
|------|---------|--------|
| 正常运行 | 绿色慢速呼吸 | 静音 |
| 预警 LV1（接近阈值 10% 以内） | 橙色闪烁 | 静音 |
| 报警 LV2（超出阈值 或 体征突变） | 红色快闪 | 间歇鸣叫 2.7kHz |
| 体征危急（HR<50 或 >130 或 SpO₂<90%） | 红色脉冲 | 鸣叫 |
| 传感器无数据 | 蓝色慢闪 | 静音 |
| 配网模式（AP 热点） | 青色呼吸 | 静音 |

## OTA 双 slot 分区

| 分区 | 地址 | 大小 | 用途 |
|------|------|------|------|
| ota_0 | 0x010000 | 1536 KB | 固件 slot A |
| ota_1 | 0x610000 | 1536 KB | 固件 slot B |
| nvs | 0xC10000 | 64 KB | NVS 存储 |
| ota_data | 0xC20000 | 16 KB | OTA 状态 |

固件 869 KB，剩余约 528 KB 可用于未来扩展。
