# 07 · 数据字典 (v2.2)

数据库: SQLite。容器启动时执行 `SCHEMA_FILE` 自动建表（`CREATE TABLE IF NOT EXISTS`），
旧库首次升级时新增表会自动补齐，无需手动迁移。

共 15 张表：`devices, telemetry, telemetry_1m, thresholds, alarms, users, sessions,
ota_images, patients, patient_devices, vitals, orders, lab_results, io_log, backup_log`

---

## 1. devices 设备

| 列 | 类型 | 说明 |
|----|------|------|
| id | TEXT PK | 设备唯一 ID（envmon-xxxxxx） |
| name | TEXT | 设备显示名 |
| online | INTEGER | 0/1 |
| last_seen | TEXT | 最后心跳 ISO 时间 |
| fw_version | TEXT | 固件版本 |
| created_at | TEXT | |
| updated_at | TEXT | |

---

## 2. telemetry / telemetry_1m 环境数据

原始 telemetry: 每上报一次一条，`device_id + ts` 唯一
1m 聚合 telemetry_1m: 每分钟聚合一次，`device_id + ts_minute` 唯一

字段: `device_id, ts, temp_c, hum_pct, pres_hpa, rssi, alarm_flag`

## 5. users / sessions 用户与会话

users: `id, username, display_name, password_hash, role(viewer/admin), sound_alarm, last_login, created_at`
sessions: `token, user_id, expires_at` （`SESSION_TTL_HOURS` 控制有效期，默认 168h）

## 11. lab_results LIS 检验 (v2.1)

| 列 | 类型 | 说明 |
|----|------|------|
| patient_id | INTEGER | FK |
| source | TEXT | lis / blood_gas / manual |
| item_code | TEXT | 项目编码 (pH / Lac / K / Na / HGB / PLT / Cr) |
| item_name | TEXT | 项目名 |
| value | REAL | 结果 |
| unit | TEXT | 单位 |
| ref_min / ref_max | REAL | 参考范围 |
| result_ts | TEXT | 结果时间 |
| critical | INTEGER | 危急值标记 (自动计算) |
| created_at | TEXT | |

危急值逻辑: `value` 超出 `[ref_min - (ref_max-ref_min)/2, ref_max + (ref_max-ref_min)/2]`

## 12. io_log 出入量 (v2.2)

| 列 | 类型 | 说明 |
|----|------|------|
| patient_id | INTEGER | FK |
| ts | TEXT | 记录时间 |
| direction | TEXT | **in** 入 / **out** 出 |
| kind | TEXT | fluid / urine / stool / drain / suction / emesis / other |
| sub_type | TEXT | 具体类别（生理盐水 / 白蛋白 / 血 / 尿 / 胃液 / 痰） |
| amount_ml | REAL | 体积 mL |
| amount_g | REAL | 重量 g |
| route | TEXT | iv / oral / po / drain / np / rectum / urine |
| note | TEXT | 备注 |
| source | TEXT | manual / his / other |
| operator | TEXT | 操作者 |
| unique_id | TEXT | 上游系统 ID |
| created_at | TEXT | |

净平衡计算: `SUM(amount_ml + amount_g) 分组 direction`，单位统一折算为 mL 当量。

## 保留策略

| 表 | 保留 |
|----|------|
| telemetry | 7 天 |
| telemetry_1m | 400 天 |
| alarms | 30 天 |
| sessions | SESSION_TTL_HOURS |
| backup 文件 | BACKUP_INTERVAL_DAYS（默认 3 天，仅保留 3 天内的） |
| vitals / orders / lab_results / io_log | 永久 |
