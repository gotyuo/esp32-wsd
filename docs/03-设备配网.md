# 03 · 设备配网与无线接入指南

固件首次上电（或未保存 WiFi 配置时）会自动进入 **AP 配网模式**。整个过程约 1 分钟，仅需一部手机。

## 配网步骤

1. **给设备上电**。屏幕显示 `CONFIG MODE`，LED 呈**青色呼吸**，表示已进入配网模式。
2. **手机连接设备热点**。打开 WiFi，找到并连接形如 `ENVMON-XXXXXX` 的开放热点（无密码）。
3. **打开配网页**。
   - 安卓：连接后通常会自动弹出配网页；
   - 若未弹出，用浏览器访问 `http://192.168.4.1`（iOS 可访问 `http://hotspot-detect.html` 或直接访问 `192.168.4.1`）。
4. **填写配置并提交**：
   - **WiFi 名称**：从扫描列表选择或手动输入；
   - **WiFi 密码**；
   - **服务器地址**：后端服务器的 IP 或域名（设备必须能访问到它）；
   - **MQTT 端口**：默认 `18830`（与 docker-compose 的 `MQTT_PORT` 一致）；
   - **MQTT 用户名/密码**：与服务器 `init_mosquitto.sh` 创建的账号一致（默认 `envmon`）；
   - **设备编号**：留空则自动生成 `envmon-xxxxxx`；
   - **上报间隔**：默认 10 秒。
5. 点击 **保存并连接**。设备自动重启并连接家庭 WiFi 与服务器。

## 配网成功的标志

- 屏幕顶部状态点变**绿**，显示 `MQTT`；
- LED 变为**绿色呼吸**；
- 服务器仪表盘 `http://<服务器IP>:8627` 出现该设备并显示"在线"，数据开始刷新。

## 重新配网 / 修改配置

- **方式一（推荐）**：设备运行时通过串口（115200）发送命令 `config`，立即回到配网模式；
- **方式二**：发送 `factory` 清除全部配置并重启，自动进入配网模式。
- 若设备连不上已保存的 WiFi，会持续以指数退避重连；长期断网不会自动进入配网模式（避免误触发），请用串口命令处理。

## 串口命令一览（115200 波特率）

| 命令 | 作用 |
|------|------|
| `config` | 立即进入 AP 配网模式 |
| `factory` | 恢复出厂（清除配置）并重启 |
| `status` | 打印当前 WiFi/MQTT/堆内存/最新读数 |

## 常见问题

- **搜不到 `ENVMON-xxxx` 热点**：确认 LED 是青色呼吸（配网态）。若是蓝色慢闪说明在尝试连已保存的 WiFi；用串口发 `factory` 清除后重试。
- **配网页打不开**：确认手机已连上设备热点，并关闭手机的"移动数据"和"私有 WiFi 地址/随机 MAC"。
- **保存后连不上服务器**：确认服务器地址、端口 `18830`、MQTT 账号密码三者与服务器端一致；服务器防火墙需放行 18830。
