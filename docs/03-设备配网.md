# 03 · 设备配网与无线接入指南 (v2.3)

固件首次上电（或未保存 WiFi 配置时）自动进入 **AP 配网模式**。v2.2 起扫描仅 2.4G 信道，耗时约 **1.5 秒**（v1.0 为 13 秒）。

## 服务器接入模式（v2.3 新增）

配网页「服务器（MQTT）」卡片顶部新增 **LAN 自动发现 / 手动指定** 切换按钮，二选一：

| 模式 | 适用场景 | 操作 |
|------|----------|------|
| **局域网自动发现**（默认） | 设备与服务器在同一内网，无需记 IP | 切换为 LAN 模式，**不填**服务器地址；设备启动后在同一无线网下广播 UDP 探测 `239.255.1.1:12091`，收到服务端应答后自动保存 MQTT 配置并重启 |
| **手动指定** | 服务器在外网 / 跨机房 / 需要固定 IP | 切换为手动，填写服务器公网 IP 或域名 + MQTT 端口 + 用户名/密码 |

### 局域网自动发现工作原理
- 设备：WiFi 连上后若 `mqtt_host` 为空且 `server_mode == 0`，则在多播组 `239.255.1.1:12091` 上每 **4s** 广播一次 `"ENVMON?"`，**45s** 内无应答自动回落 AP 配网让用户手动指定。
- 服务器：运行 `envmon-discovery` 服务（见 `02-服务器部署.md`），收到探测后回复 JSON `{"ip":"<本机LAN IP>","port":18830,"user":"envmon","pass":"envmon"}`，设备收到即保存配置并重启。
- 成功后 `server_mode` 自动切换为"手动"，下次开机直接连 MQTT，不再探测。

> 首次上手：保持默认 LAN 模式，填好 WiFi SSID/密码后点"保存并连接"，无需记服务器地址。

## 配网步骤

1. **上电**。屏幕显示 `CONFIG MODE`，LED **青色呼吸**。
2. **手机连接热点** `ENVMON-XXXXXX`（开放，无密码）。
3. **打开配网页**：
   - 安卓：通常自动弹出；否则访问 `http://192.168.4.1`
   - iOS：访问 `http://192.168.4.1`
4. **填写**：
   - WiFi SSID / Password
   - 服务器模式：**局域网自动发现**（默认，**留空即可**）/ 手动指定（填 IP 或域名）
   - MQTT 端口（默认 `18830`）
   - MQTT 用户名/密码（默认 `envmon`）
   - 设备编号（留空自动生成 `envmon-xxxxxx`）
   - 上报间隔（默认 `30` 秒）
5. **保存**。设备重启、连 WiFi。

## 关键行为变化（v2.3）

| 版本 | 变化 |
|------|------|
| v1.0 | 首次需手动填服务器 IP；STA 连不上无限重试 |
| v2.2 | AP 扫描 1.5s；STA 60s 未连回落 AP |
| **v2.3** | **新增 LAN 自动发现**（留空服务器地址即可，服务器需运行 discovery 服务） |

## 成功标志

- 屏幕顶部状态点变 **绿**，显示 `MQTT`
- LED **绿色呼吸**
- Web 台 `http://<服务器IP>:12090` → 设备"在线"

## 重新配网

- **串口命令**（115200）：`config` → 立即进 AP 模式；`factory` → 清除全部配置并重启（清除后回到 LAN 模式）
- **OTA 场景**：配网失败时设备自动回落 AP，无需拔电重烧
- 想切回手动模式：进 AP 配网 → 服务器模式切为"手动指定" → 填 IP → 保存

## OTA 远程升级（v1.7 起）

无需串口/拔电。Web 台上传 bin → 服务器 `/api/ota/upload` → 推送设备 → 双 slot 切换 + 自动回滚。

- 上传：`POST /api/ota/upload`（multipart，含 `version`）
- 查询：`GET /api/ota/version`
- 下载固件：`GET /api/ota/image`
- 推送：`POST /api/ota/push/{device_id}`
- 分块下载 + SHA256 校验
- 首次启动校验失败 → 自动回滚到另一 slot
- 当前固件 v2.2：871 KB，1.5 MB slot 内
