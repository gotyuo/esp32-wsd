# 02 · 服务器部署指南（Docker）(v2.2)

> 目标环境：任意 Linux 服务器（Ubuntu 20.04+/Debian 11+/CentOS 8+）
> 需安装 Docker + Docker Compose v2。

## 一、端口与账号规划

| 服务 | 对外端口 | 用途 |
|------|---------|------|
| Mosquitto MQTT | **18830** | 设备数据接入（`envmon/{device_id}/*`） |
| 后端 Web/API | **12090** | FastAPI 管理台、REST、WebSocket |
| (已废弃) | ~~8627~~ | v1.0 用，v2.2 已改为 12090 |

端口 12090/18830 均为非常规值，可降低被公网扫描概率。

防火墙：

```bash
# ufw
sudo ufw allow 18830/tcp
sudo ufw allow 12090/tcp
# firewalld
sudo firewall-cmd --permanent --add-port=18830/tcp --add-port=12090/tcp
sudo firewall-cmd --reload
```

## 二、部署步骤

```bash
# 1. 上传 server/ 目录到 /opt/envmon
sudo cp -r server /opt/envmon

# 2. 设置环境变量（首次部署必填）
cd /opt/envmon
cp .env.example .env
# 编辑 .env：
# ADMIN_USER=admin
# ADMIN_PASS=admin123
# MQTT_PASS=envmon-secret

# 3. 启动
docker compose up -d

# 4. 验证
curl http://127.0.0.1:12090/api/health
# → {"status":"ok",...}
```

## 三、目录与挂载

| 挂载路径 | 容器内 | 用途 |
|---------|--------|------|
| /opt/envmon/data | /data | SQLite + 备份（默认 3 天保留） |
| /opt/envmon/mosquitto | /mosquitto | MQTT 数据 |

`envmon.db` + `backups/envmon-<timestamp>.db` 都落在这里。

## 四、docker-compose.yml 关键项

```yaml
services:
  backend:
    build: .
    container_name: envmon-backend
    restart: unless-stopped
    ports:
      - "${WEB_PORT:-12090}:12090"
    environment:
      - DB_PATH=/data/envmon.db
      - SCHEMA_FILE=/app/schema.sql
      - BACKUP_DIR=/data/backups
      - MQTT_HOST=mosquitto
      - MQTT_PORT=18830
      - MQTT_USER=envmon
      - MQTT_PASS=***
      - ADMIN_USER=admin
      - ADMIN_PASS=***
      - SESSION_TTL_HOURS=168       # cookie 有效期
      - BACKUP_INTERVAL_DAYS=3      # 自动清理备份
```

## 五、数据目录 schema 自动建表

容器启动时读取 `SCHEMA_FILE` 自动建表（15 张）：

- 设备/传感器：`devices`, `telemetry`, `telemetry_1m`, `thresholds`
- 报警：`alarms`
- 用户/会话：`users`, `sessions`
- OTA：`ota_images`
- **ICU (v2.1)**：`patients`, `patient_devices`, `vitals`, `orders`, `lab_results`, `backup_log`
- **ICU (v2.2)**：`io_log`（出入量）

## 六、备份策略

- 手动触发：`POST /api/backup`（管理员）
- 自动清理：`BACKUP_INTERVAL_DAYS` 参数控制，超出自动删除
- 备份路径：`/data/backups/envmon-<ISO>.db`
- 备份文件带 SHA256 校验，写入 `backup_log` 表

## 七、升级固件到新版本

```bash
# 1. 重新拉取代码
git pull
# 2. 重建镜像
docker compose build backend
# 3. 重启容器
docker compose up -d backend
# 4. 若使用 OTA，在 Web 台 /api/ota/upload 上传新 bin
```

**注意**：v2.1/v2.2 增加 `io_log` 新表。旧 DB 已存在时容器启动会自动 `CREATE TABLE IF NOT EXISTS`，无需重新初始化。
