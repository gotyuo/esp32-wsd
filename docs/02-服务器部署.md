# 02 · 服务器部署指南（Docker）

> 目标环境：任意 Linux 服务器（Ubuntu 20.04+/Debian 11+/CentOS 8+ 均可），
> 需安装 Docker 与 Docker Compose v2。

## 一、端口与账号规划

| 服务 | 对外端口 | 用途 |
|------|---------|------|
| Mosquitto MQTT | **18830** | 设备数据接入 |
| 后端 Web/API | **8627** | 管理仪表盘、REST API、WebSocket |

端口为刻意选择的非常规值，可降低被公网扫描的概率；如需修改，编辑 `server/.env`。

防火墙示例（仅放行必要端口）：

```bash
# ufw
sudo ufw allow 18830/tcp
sudo ufw allow 8627/tcp

# firewalld
sudo firewall-cmd --permanent --add-port=18830/tcp --add-port=8627/tcp
sudo firewall-cmd --reload
```

## 二、部署步骤

```bash
# 1. 上传 server/ 目录到服务器，例如 /opt/envmon
cd /opt/envmon

# 2. 准备配置
cp .env.example .env
vi .env            # 修改 MQTT_PASS、ADMIN_TOKEN（强烈建议）

# 3. 生成 MQTT 账号密码文件（首次执行一次）
bash ../scripts/init_mosquitto.sh envmon "你设置的密码"

# 4. 构建并启动
docker compose up -d --build

# 5. 验证
docker compose ps
curl http://127.0.0.1:8627/api/health
```

浏览器访问 `http://<服务器IP>:8627` 即可打开管理仪表盘。

> **国内服务器拉镜像较慢？** 可在 `/etc/docker/daemon.json` 配置镜像加速器，例如：
> ```json
> { "registry-mirrors": ["docker.1ms.run", "docker.xuanyuan.me", "docker.m.daocloud.io"] }
> ```
> 修改后执行 `sudo systemctl restart docker`。

## 三、目录结构

```
server/
├── app/                  # FastAPI 后端源码
│   ├── main.py           # 主程序（REST + WebSocket + 报警判定）
│   ├── db.py             # SQLite 数据层
│   ├── mqtt_bridge.py    # MQTT 接入桥
│   ├── aggregator.py     # 每分钟聚合 / 离线检测 / 数据保留
│   ├── models.py
│   └── static/index.html # 管理仪表盘（单文件，无外部依赖）
├── schema.sql            # 数据库建表脚本
├── init_data.sql         # 初始化数据
├── requirements.txt
├── Dockerfile
├── docker-compose.yml
├── .env.example
├── data/                 # SQLite 数据文件（自动生成，注意备份）
└── mosquitto/
    ├── config/mosquitto.conf
    └── config/passwd     # 由 init_mosquitto.sh 生成
```

## 四、常用运维命令

```bash
docker compose logs -f backend        # 查看后端日志
docker compose logs -f mosquitto      # 查看 Broker 日志
docker compose restart                # 重启
docker compose down && docker compose up -d --build   # 更新代码后重建

bash scripts/backup_db.sh /data/backups     # 手动备份数据库
# 自动备份（每天 3 点）:
crontab -e
0 3 * * * bash /opt/envmon/scripts/backup_db.sh /data/backups
```

## 五、数据库说明

SQLite 文件位于 `server/data/envmon.db`，启动时自动执行 `schema.sql` 建表：

- `devices` — 设备档案与在线状态
- `telemetry` — 原始遥测（默认保留 7 天，环境变量 `RAW_RETENTION_DAYS` 可调）
- `telemetry_1m` — **每分钟聚合记录**（默认保留 400 天），历史曲线数据源
- `thresholds` — 阈值配置（`*` 为全局默认，设备级优先）
- `alarms` — 报警事件（触发/恢复时间、原因）

## 六、不用 Docker 的本地调试
